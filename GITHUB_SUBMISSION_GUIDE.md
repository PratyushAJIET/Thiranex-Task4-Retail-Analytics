# GitHub Submission Instructions
1. Extract the complete ZIP archive.
2. Run `retail_analytics.ipynb` in Google Colab with `customers.csv`, `products.csv`, `transactions.csv` uploaded.
3. Create a PUBLIC GitHub repository named `Thiranex-Task4-Retail-Analytics`.
4. On GitHub choose Add file > Upload files. Drag the project files **and charts folder**, not just the ZIP.
5. Confirm the charts folder contains 5 PNG files, and README renders correctly.
6. Commit message: `Add Task 4 End-to-End Retail Analytics Project`.
7. Copy the URL `https://github.com/YOUR_USERNAME/Thiranex-Task4-Retail-Analytics` and submit it in the Thiranex Task 4 form.
8. Keep the synthetic-data disclaimer. Check with Thiranex that synthetic data are permitted before submitting.
